情绪

关闭后回到「收到消息就整段回复」：不再有心境累积，也不会因为心境而选择沉默。回不回不是掷骰子——它由当前心境、与对方的关系、话题兴趣，以及长期人格札记共同决定，所以有时候她真的不说话。

身份文件写死「她是谁、什么不做、怎么说话」，模型不可改写。这里没有手写人设的输入框。想换一套原则，把 <id>.json 放进 %APPDATA%\lingyu\identity\，同名会覆盖内置身份。身份里还可以写 self_narrative（第一人称自述）与 style_samples（表达样例）。

微信里等 10 秒是不可接受的，所以默认只在「表达」这一步调模型；心境更新、情节记忆、札记筛选都有确定性规则实现。切成「表达 + 札记」时，模型每天最多写一条人格札记，且必须带来源或反例，校验不过就回退规则。

札记是全局的（不分会话），每天最多写一条，可修订、可撤回。它只保存来源引用与会话哈希，不重复存聊天原文；撤回或超过有效期的条目不会再进表达提示词。

兴趣（她愿意聊什么）

兴趣回答的不是「我现在什么感受」，而是「我一直对什么有兴趣」。它分两层，没有可以填的输入框：
· 根源：身份文件里 interests.roots 写死的底色——软件 / 艺术 / 工程机械 / 历史 / 情绪关系…，每一格都带一句「我为什么一开始就在意这个」。任何机制都改不了它。
· 演化值：聊得开心就朝上走，聊得难受就朝下走，但每次只走一小步，而且永远朝根源回归。上限是「根源 ± 可塑性的一半」——所以再喜欢也变不成另一个人。
兴趣只调制注意度：高的时候更愿意接话、话也说得更放开、回得更快；低的时候收着说；低到极端且关系还不近时，它可以只是听着不回。下面每个会话显示的是它现在的前三名兴趣。

沉默与开口（也是她的决定）

这里没有「静默时段」「群级节流」「回复间隔」「允不允许主动开口」这些选项。是否追问、是否保持沉默由表达层（L4）判断，延迟反应、降低强度、暂时回避由心境（L1）推导——做成设置项就等于让你替她决定。
· 隔多久回：被激到时先压住反应、停几秒再回；心境为正时几乎立刻回，停顿上限 8 秒；
· 要不要接话：话题正对她胃口就更愿意开口，提不起劲就收着说，极端情况下可以不接；
· 几点不说话：深夜会收着说，也不会主动找人（按本机时间判断，不用你填起止时间）；
· 要不要重新开口：沉默超过身份文件里的 silence_reopen_hours 才够格，同一段沉默只开口一次。
这些判断的理由都会写进「运行日志」，例如「情绪 [张三] 第 7 轮：想念 0.52｜话题对胃口，先停 1.6s（share）｜2 条，间隔 0.9s」。

链接解析

解析链接内容

内置 yt-dlp：媒体站点（YouTube / Bilibili 等）取标题、作者、时长、简介；普通网页取标题与摘要。解析结果以「[链接] …」附在该条消息之后，让机器人能就链接内容回应。

开启时只处理媒体平台链接（抖音 / 快手 / B 站 / YouTube / X / 小红书 / 微博 / TikTok 等），购物、团购、新闻、公众号这类链接不解析、不下载、也不会回「无法解析」——它们本来就没有音视频可发。关掉后任何链接都会尝试解析（不推荐，容易在群里刷出没用的提示）。

白名单之外的站点写在这里，子域同样命中（填 qq.com 连 v.qq.com 一起支持）。命中后按「其它媒体」走内置 yt-dlp 通用提取。

抖音走「浏览器桥」解析：用本机 Chrome/Edge 打开一次作品页、由页面自己完成风控签名，无需登录、也无需 Cookie（要求系统装有 Edge 或 Chrome，Windows 10/11 自带 Edge）。小红书直接读笔记页里的内嵌数据（服务端渲染，不需要签名），并用移动端 UA 请求——桌面 UA 会被要求登录。但分享链接里必须带 xsec_token：手工拼的 explore/<id> 会被跳到「当前笔记暂时无法浏览」，所以请直接粘贴 App 里「分享 → 复制链接」的原文。极少数笔记仍要求登录态，这时才需要 cookies.txt。微博等站点会对不带 Cookie 的请求返回 403，同样需要 cookies.txt（在浏览器里登录后用扩展导出一次）。文件不存在或留空时按原样走匿名请求，这些站点会解析失败并给出提示。

固定提示（不经过大模型）

私聊与群聊都生效：群里不必 @ 机器人，只要消息里有链接就会回固定提示，并把解析结果（推文卡片 / 视频 / 文件）发回当前聊天。提示语由这里写死，不调用大模型。关掉「模型仍接话」后，带链接的消息就只回提示与解析结果，不再烧 token。

下载并回发（谨慎）

开启后会向真实聊天发送文件，请谨慎。任何含链接的消息（私聊 / 群里不必 @ 机器人）都会下载回发，不限「触发回复」的那条。

微信对单文件有体积上限，且随会话类型不同：自聊 / 文件传输助手最宽松（高速传输可达 10 GB），普通聊天较严（旧版 100 MB）。设得过大容易下载到发不出去的文件；默认 100。

下载失败会自动重试，默认 3 次（两次之间退避 1.5 秒 / 3 秒）。B 站偶发的 Unable to extract initial state、超时、连接被重置都靠这个救回来。体积超限、图文作品、站点不支持这类确定性失败不重试，直接放弃。

重试用尽仍失败时，往当前聊天发一句「下载失败 + 原因」，免得链接发出去像石沉大海。关掉则只写日志。

附件没发成功时最多再试几次，默认 2。两个方向都用这个次数：微信明确拒绝（附件压根没粘上去）会整条重来；附件粘进去了、但回车没被微信接受（大文件粘贴后微信还要先拷原始文件、生成卡片，这期间的回车会被丢掉）只补按回车、不重新粘贴，所以不会重复发送。调大更耐折腾，代价是发送失败时会多占一会儿发送通道。

下载目录总占用超过上限时，每次下载完成后自动删除最旧的文件，直到降到上限以内（正在下载/发送的文件不会被删）。默认 1024 MB（1 GB）；填 0 表示不限制。

X（Twitter）推文卡片

检测到 X / Twitter 推文链接时，本地把推文渲染成一张图片（头像、昵称、认证、正文、配图）发回聊天；推文含视频时还会把视频下载下来一并回发。需先开启上面的「下载并回发」。

推文有多张配图时，按原比例竖排合成一张长图（一条消息发完）——不拼裁切网格，也不拆成多条消息，画面一张都不切。单图同样按原比例铺满。

中文推文不翻译（省 token）；英、日、韩、俄、阿、泰等外文会先翻成目标语言，卡片正文用译文、原文缩成灰色小字附在下面。翻译走上面「模型设置」里的接口，未配 API Key 或调用失败时自动跳过，卡片仍按原文渲染。

小红书笔记卡片

检测到小红书笔记链接时，本地把笔记渲染成一张图片（头像、昵称、标题+正文、配图、赞/评论）发回聊天。配图竖排合成一张长图（一条消息发完，不裁切、不拆条），超过 4 张时页脚标「共 N 张图」。视频笔记在卡片之后再下载视频一并回发；图文笔记只发卡片，不逐张发原图。需先开启上面的「下载并回发」。

撤回

应急撤回

机器人偶尔会发出不该发的东西（违规视频、解析错的素材）。开启后，聊天里有人发一句「@机器人 撤回」，机器人就会撤回自己最新发出的那条消息——撤的是消息不是文件，微信侧对方也看不到了。只对 2 分钟内发出的消息有效（微信限制），超过就只能手动删。

只认「指令词 + 允许的后缀」（撤回 / 撤回一下 / 撤回吧 / /撤回 / @机器人 撤回），像「别撤回」「撤回的消息看不到」这种日常对话不会被当成指令。

推荐开启：群里出现「撤回」两个字太常见，不 @ 容易误触发。私聊不受此项影响。

谁能下指令

默认关闭：群里任何人都能喊停——违规内容越快撤掉越好。若担心被乱用，可打开并填上管理员昵称（与微信里显示的昵称一致）。

撤回范围与回执

微信只提供「撤回最新一条」，所以要撤到某个视频，可能得连它后面发的提示一起撤。默认时间窗 110 秒（微信上限 2 分钟，留点余量；填 0 表示不按时间筛，但仍受微信 2 分钟限制）、最多撤 2 条。

避免「刚撤完又冒出来一条同样的视频」：正在下载的内容会被直接丢弃，不再发送。

回执是固定文案，不经过大模型。失败常见原因：消息已超过 2 分钟、微信窗口被最小化/遮挡、当前微信版本控件不可识别。

模型设置

这里的 Temperature 只影响模型的随机程度，不是「它说话的风格」——语气、长短、分几条、隔多久，都由情绪引擎与身份文件决定。

图像识别

关闭时图片只以「[图片]」文本进入上下文。开启前请确认上面的模型支持图片输入（如 qwen-vl-max、glm-4v、gpt-4o）；DeepSeek 的 deepseek-chat 不支持。
